# PARKSAFE v1.0.0

**Initial public release — 21 August 2026**

## Highlights

- Vehicle entry and exit workflows with parking-fee calculation
- Configurable parking areas, floors, and individual slots
- Live availability and maintenance status
- Receipt generation with payment QR code support
- Parking history with staff-authorised deletion

## Getting started

See the [README](README.md) for local setup and configuration.

## Notes

- This release uses SQLite for local development.
- Configure environment variables from `.env.example` before deploying.
